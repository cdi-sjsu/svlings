# Welcome

A **module** is the basic building block of a hardware design. Picture a
small box with wires going into it and wires coming out of it. Inside
the box, you describe what it does with those wires. That's a module -
you'll get the full picture in the next section. For now, all you need
is the loop:

1. Open the exercise file below.
2. Read the comment at the top - it tells you exactly what's broken.
3. Fix it, save the file.
4. Run `svlings verify`.

Repeat that, section after section, and by the end you'll have a real
feel for the language - one small circuit at a time.

## Running the checks

```
svlings verify
```
